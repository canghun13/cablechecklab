Calculation notes

Charging

The preliminary electrical ceiling is the minimum of device target, active charger-port output, and cable power rating. A missing PPS or vendor protocol is reported as an unresolved requirement; the tool does not invent a fallback wattage.

Display payload

The planner multiplies active width × height × refresh × bits per pixel × display count, applies the selected chroma factor, then adds a user-selected timing overhead estimate. It compares that estimate with known usable DP payload rates. It is not an exact CVT timing generator, a DSC model, or a host/display-count verdict.

Multi-port power

The planner screens device targets against per-port ceilings and the entered simultaneous total. When demand exceeds the budget, it reports the shortfall but does not allocate it proportionally. The exact manufacturer table remains authoritative for the occupied port combination.

Corrections

Standards, products, and operating systems change. Report an error with the page URL, affected result, exact product model, and a public source to canghun13@naver.com.
