Rate reference

Use the rate that is available to the path.

USB performance labels describe a signaling class. DisplayPort planner values below are usable encoded payload, not raw lane signaling.

Consumer USB data labels

Preferred public labelDeclared signaling class

The Data Path Checker uses the minimum host, cable, hub, and device label as a declared ceiling. Its visible overhead field is a user planning assumption, not a standardized efficiency guarantee.

Topology boundaries

  • Two conventional DP Alt Mode lanes can coexist with a SuperSpeed USB lane pair.
  • Four conventional DP Alt Mode lanes prioritize video and retain only the separate USB 2.0 path for native USB traffic.
  • USB4 dynamically shares tunneled protocol traffic and can operate up to 80 Gbps over certified 80 Gbps cables.
  • Thunderbolt 4 is a 40 Gbps class; Thunderbolt 5 supports 80 Gbps bidirectional and up to 120 Gbps in its display-oriented boost mode.
