Reference · evidence boundaries

Keep four different numbers and roles apart.

Port labels, negotiated class, shared allocation, and application throughput answer different questions.

Quick distinctions

EvidenceWhat it establishesWhat it does not establish

Shared upstream budgetFinite planning pool for simultaneous clientsEqual per-port allocation

Safe fallback evidence

  • A segment declared below the target is a hard planning ceiling.
  • A direct target pass plus an intermediary failure implicates the intermediary layer.
  • An unknown cable claim remains unknown; connector fit is not a substitute.
  • Missing USB4 enumeration is a reason to recheck the path, not proof of one defective item.
  • A browser cannot automatically read the physical cable’s certification or the native negotiated USB link.
