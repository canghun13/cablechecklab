    A signaling rate is not a file speed

    USB performance labels describe the link’s signaling class. Real transfer speed also depends on encoding, protocol, tunneling, storage media, queue depth, shared traffic, thermals, drivers, and the benchmark workload.

    The overhead field is deliberately visible. It supports planning without presenting one invented efficiency percentage as a standard guarantee.
