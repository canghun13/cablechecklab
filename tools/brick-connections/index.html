Different decisions, not one repeated verdict

Component reuse, physical/program port ownership, IR broadcast addresses and human control routes are separate tasks. A correct plug family cannot fix a duplicate program port; an extra hub port cannot give two PF receivers independent commands on the same address.

Try an error you can actually resolve

Example: choose Technic 88012, then compare the distance sensor physically plugged into C with the default program setting D. Four tasks can fit four sockets and still have an incorrect map. Change that program selection to C; for a Pybricks DriveBase, separately identify two different rotation-sensing motor rows.
