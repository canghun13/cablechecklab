    Unknown is not a failed trigger

    Not every module exposes the same indicator or meter. Select “not observed” when there is no usable observation. A silent speaker is not evidence that the module never received a hit: voice assignment, kit mapping and monitor routing are later stages.

    Substitute one approved variable

    First establish a documented compatible pad, input mode and lead. Then record one target hit and restore the baseline between trials. An approved known-good lead changing the result implicates the original lead/path; it does not prove a broken conductor. A fault following a pad can include its profile/configuration, not only hardware damage.

    Some modules disable an analog input when a digital pad is assigned the corresponding resource. Audit the exact assignment before buying another cable. For a missing rim/choke, compare the declared feature support and any split-mode trade-off. Double hits and cross-triggering also need the exact mounting/profile guidance, not universal threshold numbers.

    A concrete layer change

    Example: compatible baseline, a target trigger indication, but no target sound. The next check is the module’s kit/mapping/monitor path, not an unapproved cross-swap. If the trigger observation is unknown, collect it or record that it is unavailable; do not convert it to “no.” Copy or print preserves entered observations and the uncertainty boundary.

    No sound is generated or recorded, no connected hardware is scanned and no reset/opening/rewiring procedure is prescribed. See the source limits.
