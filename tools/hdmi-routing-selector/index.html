    Device class is only the first filter

    A switch selects among sources for one output. A splitter duplicates one selected source. A matrix provides selectable source-to-output crosspoints. A multiviewer composites multiple sources into one picture. Some products combine classes, but their EDID, scaling, audio, CEC, HDCP, and bandwidth behavior still needs separate evidence.
