    Work through a concrete example

    Example: a device whose exact manual limits its optical sensors to 1.0 cannot use 2.0 stations. Index support for both generations does not make a mixed 1.0/2.0 station set valid. An independently camera-tracked device is a separate path, not automatically another Lighthouse device.

    What this result decides

    The result checks optical-generation intersection only. Radio receivers, app support, shared coordinate spaces, synchronization and wired-PCVR video/USB requirements are separate decisions.

    Primary examples are not a device database

    Valve documents 1.0/2.0 station separation and older sensor limitations. Use the exact device manual for your declaration; no complete model compatibility list is embedded.

    Independent tracking is different

    Inside-out devices need their own supported runtime and coordinate-alignment route when mixed with Lighthouse accessories. A Quest or other headset is never assumed to work automatically.
