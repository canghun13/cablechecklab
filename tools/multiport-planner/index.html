    The total number on the box is not a port map

    Multi-port chargers commonly advertise a combined maximum, but the useful answer is the exact output table for the occupied port combination. Some chargers assign fixed tiers, some adapt, and some briefly interrupt other ports to renegotiate when a device is connected.

    Purchase checklist

    • Find the manufacturer's port-combination table, including which physical port is C1, C2, and so on.
    • Confirm each cable can carry its device target and the required protocol.
    • Leave headroom if devices must sustain power while operating, not only recharge while idle.
    • Do not assume an unused cable is ignored; behavior can differ with legacy adapters and attached devices.
