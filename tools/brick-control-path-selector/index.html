Can this controller reach the hub in the way you want?

Separate PF infrared, Powered Up remote, original app and already-installed program routes. Identify the missing receiver, runtime or supported control program.

Your setup and observations

A motor can fit the hub while the proposed remote cannot control it. Choose the human-to-hub control path independently from the motor/sensor connection and port worksheet.

    Work through a concrete example

    Example: a City 88009 hub and 88010 remote have a documented stock control route. A Technic 88012 and that remote are not assumed to have the same stock behavior. Selecting an already-installed Pybricks runtime also needs the intended control program; this page never installs it.

    Known stock routes are deliberately narrow

    City Hub 88009 with Remote 88010 has a documented original-software remote route. A Power Functions IR handset needs its matching PF IR receiver and channel setting; the battery box is not the receiver. Technic Hub 88012 documents Bluetooth to CONTROL+ and compatibility with the Powered Up app. Those statements do not prove a universal 88010-to-every-hub remote rule.

    An app needs its actual supported device and hub profile

    Choose the app appropriate to the declared hardware and check its current official device guidance. A Bluetooth logo or OS number alone does not prove every product/app combination. The selector does not download software, change permissions, scan Bluetooth or pair a device.

    A different runtime changes the control path

    Pybricks documentation supports Powered Up remotes on its supported hubs, but that is a Pybricks-firmware capability. It is not a statement about original LEGO software. Merely having that firmware installed also does not establish a loaded/running program that responds to the remote. Choose this route only when it is already installed and documented; no firmware installation is prescribed here.

    A program on the hub is a separate goal

    The SPIKE Large Hub technical description supports autonomous or streaming operation; the exact software and program still matter. A stock PF receiver is not an autonomous program host. Other stock profiles are not assumed to run a stored autonomous program just because they contain a processor or Bluetooth radio.

    Current support and legacy hardware differ

    LEGO Education ended direct SPIKE portfolio sales on June 30, 2026, while promising SPIKE App support through June 30, 2031. That is not a guarantee for every future OS or third-party runtime. This workbench supports existing connection decisions, not a purchase recommendation or competition-eligibility ruling.
