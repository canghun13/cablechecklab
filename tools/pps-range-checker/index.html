    Why “PPS supported” is incomplete

    A charger can advertise several programmable power supply ranges. The device request must fit inside one actual PPS APDO at the same time; combining the voltage from one row with the current from another creates a false match.

    PPS is not AVS. This checker accepts PPS ranges through 21 V. If the source lists an SPR AVS or EPR AVS APDO, do not enter it here as PPS.

    Copy the exact numbers

    • Use the PPS APDO for the exact charger port and occupied-port combination.
    • Use the device’s documented request, not only its advertised peak wattage.
    • Check cable current and any vendor-specific protocol after the range fits.
