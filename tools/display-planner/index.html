    Choose the right link budget

    DP Alt Mode may assign two high-speed lanes to DisplayPort while keeping USB 3 data, or use all four lanes for video. A dock can divide or tunnel that capacity again. Use the payload rate actually available through your host, cable, and dock—not the largest DisplayPort version named anywhere in the chain.

    Why “fits” is not a compatibility promise

    • The GPU and operating system must expose the target timing and number of displays.
    • Adapters and docks must support the selected link rate, lane count, color format, DSC, and MST behavior.
    • Exact CVT timings and blanking differ; the overhead control is only a planning estimate.
    • macOS and Windows can differ in ordinary MST multi-display support.
