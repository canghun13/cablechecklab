    Count equivalent groups, not every socket

    This planner handles one homogeneous pool: every retained group must support any planned dual-zone pad in this run. Do not combine a dedicated kick input, a hi-hat controller input and general trigger inputs simply because all are sockets. Reserve extra resources for two-input cymbals and digital assignments before entering the remaining demand. Run unequal pools separately.

    Keep the scarce split resource free

    Hypothetical example: four available groups, two split-eligible groups, two dual-zone pads and four single-zone pads fit only if the exact split mode/lead is supported. The two dual-zone pads occupy non-split groups first; two pairs of single-zone pads use the remaining split groups. Changing the demand to three dual-zone and four single-zone pads exceeds that pool’s capacity.

    A single-zone pad alone does not require a split. The worksheet uses the minimum splits needed and labels logical plan groups, not physical jack numbers. Transfer each assignment to the exact module input map yourself.

    A Y lead is not universal expansion

    Use only a documented two-independent-single-pad configuration. Head/rim splitting can trade away zones, choke or position features, and a stereo headphone Y lead need not perform the required wiring. Roland documents particular two-pad arrangements and settings; those examples are not support for other modules. No pinout, resistor modification or generic wiring recipe is supplied here.

    Check the split-mode sources and limits before treating arithmetic as a connection plan.
