Recommended sequence

Requirement → declared fit → measured behavior

The first two are browser checks. The last requires a tester or trustworthy system telemetry.

Build the requirement

Identify voltage, current, protocol, cable class, and active-port conditions.

Screen every declared link

Reject a mismatch; treat a match as plausible, not measured.

Verify negotiation

If behavior differs, isolate the path and observe the negotiated profile with appropriate hardware.
