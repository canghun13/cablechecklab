Pre-purchase guide

A port list is not a dock specification.

Build four requirement lists—host, displays, data, and power—then reject products that omit a must-have fact.

1. Prove the host port

  • Exact computer model and physical port.
  • USB data rate, DisplayPort Alt Mode, USB4, or Thunderbolt generation.
  • Native external-display count and operating-system policy.
  • Accepted charging power and any EPR support.

2. Describe every display

  • Resolution, refresh, bits per channel, chroma, HDR, and input type.
  • Combined payload of displays sharing the upstream link.
  • MST, DSC, Thunderbolt/USB4, or USB-graphics topology.
  • Whether mirroring is acceptable or independent extension is required.

3. Map USB and PCIe data

  • Fastest storage, network, capture, or audio device.
  • Dock upstream rate and the rate of each required downstream port.
  • Which ports share one controller or bandwidth group.
  • Explicit PCIe tunneling support for relevant enclosures.

4. Budget power

  • Power-supply wattage is not the same as power delivered to the host.
  • Subtract dock electronics and reserve, then add downstream device allocations.
  • Confirm the exact active-port table and host cable current class.
  • For more than 100 W, verify EPR across supply, dock, cable, and host.
Reject ambiguity: if an essential output mode, delivered wattage, or downstream rate is absent from the exact-model documentation, mark it unverified—not compatible.

5. Plan a return-safe test

  1. Update host and dock firmware.
  2. Test charging alone.
  3. Add one display at its target mode.
  4. Add displays one at a time.
  5. Add storage and network devices, then test simultaneous load.
  6. Reconnect after sleep and after a cold boot.
