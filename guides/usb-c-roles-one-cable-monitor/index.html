Guide · endpoint roles

One connector can carry three different directions.

Power, USB data, and display roles are related by policy, but they are not the same promise.

Keep the role vocabularies separate

FunctionOrigin roleDestination role
PowerSourceSink
USB dataHost / DFPDevice / UFP
DisplayVideo sourceVideo sink

Dual-role products can swap some roles through USB Power Delivery policy. Do not infer that behavior from the receptacle. Two computers with USB-C ports, for example, are not automatically a useful USB data connection because both may expect the host role.

Plan a one-cable monitor in four passes

  1. Confirm that the exact host port outputs video and the monitor’s exact USB-C port accepts video.
  2. Use a cable that explicitly supports the required video path and charging current.
  3. Compare the exact display payload with the usable link capacity, including lane sharing or DSC.
  4. Separately compare monitor PD output with the laptop target and monitor-hub traffic with its USB upstream pool.
Do not turn “works” into “full-featured.”
A monitor may display video but charge slowly, or it may charge while its downstream USB hub uses a reduced data path.
