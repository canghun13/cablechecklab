Video adapters

Name the source signal first.

“USB-C to HDMI” and “HDMI to USB-C” describe different products even when their connectors look reversible.

Read every path left to right

Start at the computer, console, or source output and end at the display input. Then name the signal carried at the source—not only the connector. A USB-C source might expose DisplayPort Alt Mode, a USB4/Thunderbolt display tunnel, USB data for a graphics adapter, or no video at all.

Common conversion categories

Source → displayTypical requirement
USB-C DP Alt Mode → DisplayPortPurpose-built one-way adapter/cable preserving DisplayPort; source must expose video.
USB-C DP Alt Mode → HDMIDirectional protocol adapter rated for exact resolution, refresh, color, HDR, HDCP, and audio.
DisplayPort → HDMI/DVIA passive adapter may work only when the source explicitly supports Dual-Mode DisplayPort (DP++); otherwise use an active converter.
HDMI → DisplayPortActive, directional, often powered conversion. A common DP-to-HDMI cable is the wrong direction.
HDMI/DP → USB-C display inputSpecialized powered reverse converter that supplies the USB-C display’s expected video path; verify the exact display.
USB-A → HDMI/DPUSB graphics chipset and driver, not DisplayPort Alt Mode. Workload, latency, security, and OS support matter.

“Active” does not mean “supports everything”

An active converter changes protocol, but its internal receiver, transmitter, EDID handling, firmware, and optional-feature support still have limits. A product can support a headline 4K mode while omitting HDR, variable refresh, a required HDCP version, multichannel audio, or DSC at that same timing.

Direct-path test

  1. Confirm the source port explicitly provides the source video signal.
  2. Test one known-good direct connection at a conservative mode.
  3. Add the adapter and use its documented direction.
  4. Raise refresh, color depth, HDR, or VRR one feature at a time.
  5. If the failure appears only after the adapter, compare the feature chain rather than replacing the display immediately.
